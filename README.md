# HR Attrition Analysis

**Problem:** Analyze employee attrition patterns and identify departments with higher employee turnover.

**Dataset:** IBM HR Employee Attrition dataset, 1,470 employees.

**What I did:**

* Cleaned and analyzed employee data using Python and Pandas
* Calculated overall and department-wise attrition
* Wrote SQL queries in MySQL for HR analysis
* Identified departments with higher attrition rates

**Key Findings:**

* Employees: 1,470
* Overall attrition: 16.1%
* Sales attrition: 20.6%
* Human Resources attrition: 19.0%
* Research & Development attrition: 13.8%
